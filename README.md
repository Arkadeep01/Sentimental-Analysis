# 📝 Sentiment Analysis Web App

An end-to-end Machine Learning project that classifies product reviews or social media posts into **Positive** or **Negative** sentiments. This project uses a hybrid approach of classical Machine Learning (Logistic Regression) and modern NLP preprocessing techniques.

## 📊 Features
* **Real-time Prediction:** Enter any text and get instant sentiment results.
* **Streamlit Interface:** A clean, user-friendly web UI for non-technical users.
* **Pre-trained Pipeline:** Uses TF-IDF vectorization for high-speed inference.
* **Notebook Included:** Full BERT exploration and training logic provided in `.ipynb`.

## 🛠️ Tech Stack
* **Language:** Python
* **UI Framework:** Streamlit
* **ML Libraries:** Scikit-learn, Joblib
* **NLP Tools:** NLTK (Natural Language Toolkit)
